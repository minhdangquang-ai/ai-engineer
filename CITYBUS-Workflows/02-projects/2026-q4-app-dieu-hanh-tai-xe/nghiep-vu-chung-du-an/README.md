Thư mục chứa nghiệp vụ chung cấp dự án (Tầng 2).

## File gốc

- `nghiep-vu-chung-du-an.md` — tài liệu nghiệp vụ tổng quan của dự án (ranh giới hệ thống, nguồn dữ liệu gốc, vòng đời ca, quy tắc xuyên suốt). Tên file **cố định, không dùng tiền tố ngày**.

## Quy tắc ghi thay đổi nghiệp vụ (Minh chốt ngày 2026-11-27)

- Từ nay, **bất kỳ thay đổi nghiệp vụ nào cũng ghi riêng ra một file mới** đặt trong thư mục này — không ghi lẫn vào file gốc.
- Tên file thay đổi có tiền tố ngày theo định dạng **`yyyy-mm-dd`**: `yyyy-mm-dd-thay-doi-<noi-dung-ngan>.md` (vd `2026-11-28-thay-doi-dang-nhap-ca.md`).
- Trong file thay đổi phải **chỉ rõ phần đã thay đổi**: mục/đoạn nào trong `nghiep-vu-chung-du-an.md` bị ảnh hưởng, nội dung trước → sau thay đổi, lý do thay đổi và task Jira liên quan (nếu có).
