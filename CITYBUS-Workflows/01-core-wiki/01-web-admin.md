# Web Admin & Website Citybus

> Trạng thái: **khung tài liệu** — nội dung nghiệp vụ sẽ được BA bổ sung dần từ tài liệu tổng hợp Citybus hiện có.

Phạm vi: hệ thống Smartbus Admin (quản lý tuyến, nhân sự, phân công/giờ tài, lịch sử mua vé, eLVC, báo cáo doanh thu/tuyến) và các cổng thông tin Citybus liên quan.

## Nội dung sẽ gồm
- Tổng quan hệ thống và các phân hệ
- Quy tắc nghiệp vụ dùng chung (đặc biệt: quy trình eLVC và các mốc giờ T+1)
- Liên kết tới các file chi tiết (nếu tách nhỏ sau này)
